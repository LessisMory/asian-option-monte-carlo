# Monte Carlo Pricing of Asian Options

This repository implements Monte Carlo methods for pricing arithmetic Asian options,
including correlated multi-asset structures and numerical Greeks estimation.

## Features
- Monte Carlo simulation under GBM
- Arithmetic Asian option pricing
- Correlated asset modeling
- Numerical Delta, Gamma, Vega
- Common random numbers for variance reduction

## Structure
- pricing/: option pricing engines
- greeks/: numerical Greeks estimation
- utils/: shared utilities
- experiments/: visualization and demos

## Applications
- Commodity derivatives
- Structured products
- Quantitative risk management
